# Attribution and changes

These conversions are distributed by FCP AI Toolkit for prototype testing. Upstream authors do not endorse this distribution. The original license texts are preserved without edits in `LICENSES/`; no single new license overrides any upstream file, model or condition.

- **Real-ESRGAN:** Xintao Wang and contributors; BSD-3-Clause. Official x4plus weights and source from the Real-ESRGAN project. Architecture is BasicSR RRDBNet, Apache-2.0. The helper and RRDB source files remain unchanged; the converter removes registration/training-package imports and extracts three official helper functions. The model uses native 4× scale and FP16 internal Core ML operations with Float32 I/O. Weight coverage is project-scope inference.
- **InstructIR:** Marcos V. Conde and contributors; MIT. Image/head weights are in the author's MIT-labelled model repository. The architecture includes NAFNet code by megvii-model: its MIT and inherited BasicSR Apache-2.0 notice are retained. The converter uses equivalent explicit LayerNorm forward arithmetic and replaces internal image-size padding with identity only when callers enforce the original zero-pad-to-16/crop contract. Global average pooling is retained. Two fixed prompts are encoded offline through the official text head and TaylorAI BGE-micro-v2 (MIT); only the resulting vectors are runtime inputs.
- **Practical-RIFE:** Zhewei Huang and contributors; MIT. The repository's trained-model section expressly covers linked model contents with the same MIT license. Exact IFNet source comes from the 4.25 archive; the warp helper comes from the pinned repository. The converter strips DataParallel prefixes and only the documented unused `teacher.*`/`caltime.*` checkpoint entries; the remaining load is strict. It keeps the explicit five-scale list `[16,8,4,2,1]` and a dynamic tensor timestep. It selects the final RGB result.
- **FBCNN:** Jiaxi Jiang and contributors; Apache-2.0. The official network file acknowledges BasicSR helper code; the full BasicSR license is retained. KAIR's MIT notice is also retained as an inherited provenance notice; its current pinned license snapshot does not claim to identify the exact historical copied revision. The converter removes only an unused torchvision import, strictly loads the official colour checkpoint and keeps the blind quality branch without overrides. Weight coverage is project-scope inference.

The portable conversion wrapper and vector-generation wrapper are new developer tools under `LICENSES/CONVERTERS-MIT.txt`; this grant applies only to those newly authored wrappers. All vendored source files retain their upstream licensing, unchanged content and source hash. Conversion is a change of representation and the operations described above, not retraining or an upstream release.

Source license coverage and tested image quality are separate matters. Known quality/capacity failures remain recorded in the prototype documentation; distribution is not a claim that every task or resolution is release-qualified.
